# Ziddan Ilmy Nazzarin — 3D Interactive Portfolio

A modern, animated personal portfolio redesigned from the uploaded `monties-portfolio` project. Built with **plain HTML, CSS, and JavaScript**, with **no dependencies or installation required**.

## 🚀 Run the website

1. Extract the ZIP file completely.
2. Open **`Ziddan-Portfolio-3D/index.html`** in Chrome, Edge, Firefox or Safari.
3. Move the mouse over the project cards and **drag the animated 3D globe** with your mouse or finger.

Optional: In Visual Studio Code, use **Live Server** to preview. Not required.

## ✨ New features

- Fully redesigned, responsive portfolio (desktop, tablet, mobile)
- Procedurally rendered **3D wireframe globe**, with perspective, orbital rings and satellites
- Interactive 3D globe supports mouse and touch dragging; automatically rotates
- CSS mockups for real projects; no mock project claims or fabricated live links
- Hover-tilt cards, animated ticker, entrance effects, scroll progress, pointer glow
- Animated mobile navigation and active section highlighting
- **Motion on/off** control and support for `prefers-reduced-motion`
- Accessible navigation, semantic headings, alt text, skip link and keyboard outlines
- Includes original profile photo and content adapted from the submitted portfolio
- **Offline-compatible:** no CDNs, external fonts, npm, APIs or build tools

## 🌐 Publish to GitHub Pages

1. Copy the website files (`index.html`, `css/`, `js/`, `assets/`) to the **root** of your Pages repository.
2. In the GitHub repository open **Settings → Pages → Deploy from a branch**.
3. Select `main` / `/ (root)` and save.
4. Wait for GitHub deployment. Your page should be available at the Pages URL listed in Settings.

## ✏️ Personalization

- Change sections, text, email and links in **`index.html`**.
- Change colors in **`css/style.css`** (`:root` variables).
- Change the orbital scene in **`js/script.js`** (`OrbitalScene` class).
- Replace **`assets/profile.jpeg`** to update the photo.

**Content note:** Education, GPA, projects, links and experiences were retained/adapted from the supplied portfolio. The animated project screens are decorative illustrations, not screenshots or verified live apps. Verify all personal details before publishing.
