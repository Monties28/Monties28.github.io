# Ziddan Ilmy Nazzarin — Portfolio

Responsive personal portfolio built with HTML, CSS, and vanilla JavaScript. Includes 3D tilt interactions, glass-like layered cards, ambient gradients, scroll reveals, mobile navigation, and reduced-motion support.

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Deploy to GitHub Pages
Repository: `Monties28/Monties28.github.io`
Branch: `main` · Folder: `/ (root)`

After copying these project files into your local repository folder, run:

```bash
git add .
git commit -m "Upgrade portfolio with immersive 3D design"
git push origin main
```

Then refresh https://monties28.github.io/ with Ctrl+F5.
